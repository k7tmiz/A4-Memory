# A4 Memory 2.1.0 Coordinated UI Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 交付具有触发点往返弹层动效、稳定横向主路由、统一现代设置页和完整现代记录页的 A4 Memory 2.1.0。

**Architecture:** `js/ui/layers.js` 继续作为所有标准弹层的唯一协调器，并以向后兼容的第三参数保存触发来源和运行动画；`A4Router` 继续管理持久 App Shell 的三视图生命周期。设置与记录控制器保留现有业务函数，通过语义化 DOM 与独立页面样式文件重排信息层级，不修改状态结构、后端接口或私有桥接层。

**Tech Stack:** Vanilla HTML/CSS/JavaScript、Node.js 原生测试运行器、ESLint、Vite 复制构建、Tauri v2 版本元数据。

## Global Constraints

- 不修改 `backend/`、`js/cloud.js`、后端 API、鉴权、数据库或云同步协议。
- 不修改学习记录的数据结构、统计规则、轮次生成规则或 A4 排版算法。
- 不引入前端框架或新的运行时依赖。
- 所有标准弹层继续通过 `window.A4UI` 管理滚动锁、页面隔离、焦点陷阱、嵌套层、Escape 和路由批量清理。
- `cloud.js` 缺失时前端必须正常运行，云功能显示错误而不崩溃。
- AI API Key 只允许保留在内存中。
- Classic、Paper Green、Ocean 三套现有配色必须继续生效。
- 手机、桌面、浏览器和 Tauri WebView 共享同一套业务 DOM 与控制器。
- 最终应用版本精确更新为 `2.1.0`。
- 不提交现有四张未跟踪的 `persistent-shell-mobile-*.png` 截图。

- [ ] **Step 4: Implement a backward-compatible layer motion context**

Add private helpers and state in `js/ui/layers.js`:

```js
const layerMotion = new WeakMap()
const LAYER_ENTER_MS = 300
const LAYER_EXIT_MS = 210

function readRect(element) {
  if (!element?.getBoundingClientRect) return null
  const rect = element.getBoundingClientRect()
  const width = Number(rect.width) || 0
  const height = Number(rect.height) || 0
  if (width <= 0 || height <= 0) return null
  return {
    left: Number(rect.left) || 0,
    top: Number(rect.top) || 0,
    width,
    height,
  }
}

function resolveLayerPanel(layer) {
  return layer.querySelector?.(
    "[data-a4-layer-panel], .modal-panel, .mobile-more-panel, .android-select-panel"
  ) || layer
}

function originTransform(sourceRect, panelRect, motion) {
  if (motion === "neutral" || !sourceRect || !panelRect) {
    return "translate3d(0, 10px, 0) scale(0.97)"
  }
  const sourceX = sourceRect.left + sourceRect.width / 2
  const sourceY = sourceRect.top + sourceRect.height / 2
  const panelX = panelRect.left + panelRect.width / 2
  const panelY = panelRect.top + panelRect.height / 2
  const scale = Math.max(0.72, Math.min(0.94, sourceRect.width / panelRect.width || 0.82))
  return `translate3d(${Math.round(sourceX - panelX)}px, ${Math.round(sourceY - panelY)}px, 0) scale(${scale})`
}
```

`setLayerVisible(layer, true, options)` must read `options.trigger || document.activeElement` before locking the page, unhide the layer, read the panel rectangle once, save the motion context, then animate panel and backdrop:

```js
const trigger = options.trigger || document.activeElement || null
const sourceRect = readRect(trigger)
const panel = resolveLayerPanel(layer)
const panelRect = readRect(panel)
const context = {
  trigger,
  sourceRect,
  panel,
  panelRect,
  motion: options.motion || (sourceRect ? "origin" : "neutral"),
  animations: [],
}
layerMotion.set(layer, context)
runLayerAnimation(layer, "enter")
```

`runLayerAnimation` uses `Element.animate` when available, stores every handle, and falls back to the existing CSS classes/timeouts when unavailable. Before a new phase it cancels and clears old handles. Exit keyframes start at the panel’s current computed transform/opacity when available and end at the saved origin transform. Backdrop keyframes are `0 → 1` on enter and current opacity `→ 0` on exit.

- [ ] **Step 5: Preserve layer-stack invariants during animation completion**

Make `closeLayer` await the actual exit animation promise when WAAPI exists, with a timeout fallback capped at `LAYER_EXIT_MS + 50`. `finishLayerClose` must:

```js
layer.classList.remove("a4-layer-entering", "a4-layer-closing")
layer.classList.add("hidden")
```

`closeAll({ immediate: true })` must cancel animations and never restore old-route focus. Reopening a closing layer must resolve the prior close promise with `false` without unlocking the body.

Keep CSS fallbacks only for browsers without `Element.animate`:
