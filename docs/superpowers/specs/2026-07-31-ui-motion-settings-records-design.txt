A4 Memory 界面协调与空间动效设计规格

日期：2026-07-31
状态：已确认视觉方向，待实施

1. 目标

- 所有由用户点击触发的弹层具有明确的空间来源：从触发控件附近展开，关闭时回到同一控件。
- 学习、记录、设置三个主视图按底栏顺序横向切换，方向稳定且连续。
- 设置页采用统一、轻量、现代的页面式布局，不保留突兀的深色上传区或弹窗式页面框架。
- 记录页突出高频复习任务与学习进度，同时保留现有全部功能、数据语义和跨页意图。
- 手机、桌面和 Tauri WebView 共用同一套交互规则，并遵守系统“减少动态效果”偏好。

2. 非目标与边界

- 不修改 backend/、js/cloud.js、后端 API、鉴权、数据库或云同步协议。
- 不修改学习记录的数据结构、统计规则、轮次生成规则或 A4 排版算法。
- 不引入前端框架，不绕过现有 App Shell、A4UI、A4Router 和 window.* 模块边界。
- 不用动画掩盖请求等待、失败状态或业务错误。
- 不删除任何现有设置项、记录操作、导出能力或无障碍行为。

3. 统一空间动效

3.1 弹层来源上下文

js/ui/layers.js 作为唯一标准弹层协调器，接受向后兼容的可选打开上下文。调用方可以提供触发元素；未提供时保持现有调用有效。

每个打开中的弹层保存以下运行时信息：

- 触发元素引用。
- 弹层显示前测得的触发元素矩形。
- 最终弹层面板矩形。
- 进入或退出中的动画句柄。
- 打开前焦点元素。
- 弹层所有者和嵌套层级。

触发矩形必须在锁定页面和改变弹层显示状态前读取。面板矩形在弹层可测量后读取。每段动画只测量一次起止位置，不在逐帧回调中读取布局。

3.2 动画规则

- 居中对话框、确认框和预览层：面板从触发点指向面板中心的位移开始，配合小幅缩放和透明度进入；关闭时沿原路径回到触发点。
- 底部面板和移动端选择器：保留底部面板的最终位置，但进入方向同时包含触发点的水平来源，使触发关系可感知。
- 贴近控件的菜单或气泡层：以触发控件为锚点展开，关闭时收回锚点。
- 无用户触发源的公告、自动更新提示和恢复性错误：使用克制的中心缩放与淡入淡出，不伪造来源。
- 只动画 transform、opacity 和必要的背景透明度；不动画会引起连续重排的几何属性。
- 动画时长和缓动统一使用界面动效变量。进入略柔和，退出略短，按压反馈即时。

3.3 中断与降级

- 关闭尚未完成进入的弹层时，取消旧动画并从当前视觉状态平滑退出。
- 同一弹层快速重复打开时，旧动画和旧清理回调不得解锁页面、恢复错误焦点或覆盖新状态。
- 触发元素被删除、滚出可视区或不可测量时，优先使用保存的矩形；仍不可用时使用中性回退动画。
- 路由切换批量清层使用即时清理，不向已经离开的页面反向飞回。
- 嵌套弹层只关闭最上层；底层弹层继续保持页面锁定和隔离。
- prefers-reduced-motion: reduce 下取消位移和缩放，仅保留极短透明度变化或立即完成。

3.4 无障碍不变量

现有背景滚动锁、inert/aria-hidden 页面隔离、焦点陷阱、Escape 关闭、嵌套层栈、关闭后焦点恢复和路由撤销语义必须保持。动画结束不是解除这些约束的前提；约束覆盖弹层从打开到完成清理的整个生命周期。

4. 主视图路由动效

底栏顺序固定为“学习 → 记录 → 设置”：

- 向右侧目标切换时，当前视图向左离开，目标视图从右进入。
- 向左侧目标切换时，当前视图向右离开，目标视图从左进入。
- 底栏保持挂载，活动胶囊在对应项目间平滑滑动。
- “下一个单词”只属于学习视图，离开学习时平滑收起，返回学习时恢复。
- 记录页不再叠加自下而上的内容进入动画。
- 设置页内部分类切换采用同一方向逻辑；分类轨道本身不跳动。
- 路由切换期间避免重复处理主题、鉴权和全局退出事件，继续由活动路由独占生命周期。

5. 设置页信息架构与视觉

5.1 整体结构

设置页是 App Shell 内的独立主视图，不使用返回按钮、弹窗标题栏或巨型外层空白卡片。页面由以下层级组成：

- 页面标题与必要的状态摘要。
- 账户、学习、发音、AI、更多五个分类入口。
- 当前分类内容区。
- 页面底部安全区和悬浮底栏避让区。

手机端使用紧凑的吸顶分类轨道；桌面端可使用左侧分类导航与右侧内容区。两种布局共享相同 DOM 语义和设置控制器，不复制业务逻辑。

5.2 账户分类

账户区采用轻量仪表盘结构：

- 用户身份、邮箱和在线状态。
- 云同步状态、最近同步结果和核心学习统计。
- “上传云端”和“恢复本机”使用同规格浅色操作卡或按钮。
- 上传操作仅通过海军蓝图标、文字、细边框或按压反馈体现主操作，不使用常驻黑色大块。
- 绿色只用于在线、成功和健康状态，不承担普通主按钮配色。
- 退出登录作为低强调危险操作，与同步操作保持清晰距离。

5.3 其余分类

- 学习：词书、轮次、分页、释义和学习行为设置按任务分组。
- 发音：启用状态、在线/离线方式、在线来源、离线语音包、当前生效语音和测试发音保持完整。离线语音包始终可发现，但只有选择离线 TTS 时进入主要操作状态；在线模式下用说明和弱化状态表达其用途。
- AI：提供商、模型、Base URL、临时 API Key 和测试能力保持现有安全约束。
- 更多：主题、数据、更新、关于和其他现有入口按语义分组。

Classic、Paper Green、Ocean 三套现有配色继续通过主题变量工作。设置页不得写死只适用于 Classic 的背景或状态色。

6. 记录页信息架构与视觉

6.1 默认页面

记录页默认呈现以下内容：

- 页面标题和低频工具菜单。
- “轮次 / 状态”滑动分段控件。
- 单词数、连续学习、当前轮或等价的三项核心指标。
- 今日复习焦点卡，显示待复习量、目标进度和主要复习入口。
- 最近轮次卡片列表。
- 无记录、无待复习和加载失败状态。

低频的全局查词、全部导出和清空记录放入页面工具菜单，避免与主要复习任务争夺视觉层级。

6.2 轮次视图

每个轮次默认使用紧凑摘要卡，包含轮次名称、时间、语言或类型、完成进度和主要“复习”操作。展开后提供：

- 单词及学习状态列表。
- 轮次统计和分页信息。
- 按页查看的 A4 预览。
- 上一页、下一页和页码状态；只有存在多页时显示翻页控件。
- 单轮 CSV、PDF 导出和删除等次级操作。

A4 预览默认收起，按需展开；不再让大尺寸空白纸张占据记录页首屏。现有打印预览和退出清理生命周期保持不变。

6.3 状态视图

状态分组、各状态计数、单词列表和“生成复习轮次”能力全部保留。pendingGenerateStatusKind、pendingReviewRoundId 等跨页意图字段的含义和处理路径不变。

6.4 响应式规则

- 320px 起保持操作可达、文字不重叠、工具菜单不超出视口。
- 手机端卡片单列，主要操作靠近拇指可达区域，并为悬浮底栏和系统安全区留出空间。
- 桌面端利用宽度形成摘要、列表和按需详情的清晰网格，但不把手机卡片机械放大。
- 长词、长词书名、大轮次数和多页预览必须可换行或截断，并提供完整信息的可访问名称。

7. 数据流与功能保持

- records.js 中现有统计、轮次、状态、复习、导出、删除和打印函数继续作为业务事实来源；重构只调整呈现层级和事件接线。
- settings.js 中现有读取、验证、保存、预览、下载和测试函数继续作为设置行为来源。
- 所有确认、预览、选择和错误弹层通过 A4UI 进入统一层栈。
- cloud.js 缺失时，云功能继续显示可理解错误且页面不崩溃。
- AI API Key 继续只在内存中使用；布局重构不得新增持久化路径。
- 云恢复覆盖确认、上传/下载互斥 busy 状态和按钮禁用规则保持不变。

8. 实施范围

预计修改的公开前端范围：

- js/ui/layers.js：触发来源上下文、动画生命周期和降级逻辑。
- js/ui/router.js：核验并统一主视图方向与中断处理。
- js/settings.js、js/settings-page.js：设置页结构和来源触发接线。
- js/records.js：记录页结构和来源触发接线。
- js/app.js、js/lookup.js、js/utils.js 及其他弹层调用方：向 A4UI 传递明确触发元素。
- css/style.css、css/records.css、css/settings.css：统一动效变量、响应式布局和主题化视觉。
- index.html：仅在现有 App Shell 内调整必要的设置与记录视图语义结构。
- tests/：补充动效、路由、设置和记录功能保持测试。

实际实现以最近目录规范和现有模块边界为准；没有必要的文件不修改。

9. 测试与验证

自动验证：

- 弹层保存触发矩形，并能按相同来源完成进入和退出。
- 快速开关、快速重开、嵌套弹层、Escape、路由批量清层和触发元素消失不会破坏层栈。
- 减少动态效果偏好生效。
- 主路由方向符合底栏顺序，记录页不存在额外纵向进入动画。
- 设置五个分类及现有控制项仍可访问。
- 记录页轮次、状态、复习、查词、导出、删除、A4 预览、分页和清空能力仍可访问。
- 单页 A4 预览不显示翻页控件，多页时正确显示。
- cloud.js 缺失时页面可运行。

执行命令：

- npm test
- npm run lint
- npm run build

人工验证：

- 手机窄屏、常见 Android 宽度、平板和桌面宽度。
- 浏览器与 Tauri WebView。
- Classic、Paper Green、Ocean 三套配色。
- 鼠标、触控、键盘与 Escape。
- 页面滚动位置、焦点恢复、嵌套弹层和底栏避让。
- 正常动效与减少动态效果两种系统偏好。

10. 验收标准

- 点击打开的标准弹层可感知地从所点击控件展开，并在关闭时回到同一控件。
- 自动弹层使用自然的中性动效，不出现错误飞行来源。
- 学习、记录、设置之间只有符合顺序的横向切换；记录页不再自下向上弹入。
- 设置页没有返回键、弹窗式顶栏、突兀深色上传块或无意义的大面积空白。
- 记录页首屏突出复习和进度，A4 预览默认按需展开。
- 设置和记录现有功能全部可达，数据与业务语义不变。
- 弹层期间背景不可滚动或聚焦，嵌套与焦点恢复正确。
- 动画在常规设备上流畅，中断安全，并尊重减少动态效果偏好。
- npm test、npm run lint、npm run build 全部通过。
